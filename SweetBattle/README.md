# Sweet Escape 戦闘プロトタイプ

既存ソリューション内の独立した Siv3D v0.6.16 プロジェクトです。
Visual Studio で「SweetBattle」をスタートアッププロジェクトに設定し、x64 で実行してください。
SIV3D_0_6_16 環境変数が必要です。デバッガの作業ディレクトリは既存 App を参照します。
ビルド時に exe を既存 App フォルダーへコピーします。直接起動には App/SweetBattle.exe（Debug は SweetBattle(debug).exe）を使用してください。

## 操作
- Enter: 装備決定・戦闘開始 / 結果画面から再戦
- WASD / 矢印: 移動（左側のプレイヤー領域内）
- Z / Space: 押している間射撃
- X / Tab: 2つの武器の切り替え
- C: 選択した必殺技（SP 50）
- Shift: 低速移動・グレイズ範囲表示
- P: 一時停止
- R: 即リトライ
- Esc: 装備に戻る（ウィンドウの閉じるボタンで終了）

## 実装内容・仮バランス
武器スロットはキャンディ（威力9、0.12秒間隔）とマカロン（威力7×3方向、0.32秒間隔）。
必殺技は装備画面で 1 / 2 により選択。攻撃型は敵HPを170減らして敵弾を消去、
防御型は4秒間無敵。武器の切り替えから独立しています。
HPは100、被弾ダメージ10、被弾後1秒無敵。SPは初期25、上限100、
毎秒3回復し、敵弾1発につき1回のグレイズで4獲得します。
無敵中と被弾した弾からはグレイズを獲得しません。
執事のHPは900。自機狙い5方向弾と隙間のある列弾を交互に使い、
残HP半分で発射間隔・弾速が増加します。敵HPゼロで勝利、主人公HPゼロで敗北。
勝敗表示から追加ロードなしで再戦できます。レベル・恒常成長はありません。

## 既存の仕組みの利用
Siv3D SceneManager による装備／戦闘の短い遷移と、
既存 GameObject/HitBox.h・HitBox.cpp の CircleHitBox による敵との衝突判定を利用。
自機の小さな当たり判定には線分による連続判定も使用し、弾のすり抜けを防いでいます。
元ゲームの Main・セーブデータ・リプレイ・アセット登録処理は共有しません。
時間は秒単位、最大1/120秒のサブステップで更新します。
描画用キャラクター・食べ物は図形の仮素材です。探索・ストーリーは対象外です。

## 調整する場所
Main.cpp の Weapons が武器の装備データです。Battle の初期値、emitFood、
special がHP/SP・弾幕・必殺技の調整箇所です。
将来探索を追加する場合は Battle の勝敗状態を共有データへ返す構成に拡張できます。
